#+title: RadMachine → Org Logbook Importer
#+author: Ashley Gillman, OpenAI

* Overview

This repository is intended to build a small, inspectable toolchain for importing activity from RadMachine into an Org-mode logbook.

The aim is:
1. Pull RadMachine records for a given user and date range.
2. Normalise and group those records into candidate logbook entries, this should be user-configurable
3. Present each candidate entry in Emacs for review.
4. Allow the user to edit, accept, or skip each entry.
5. Insert accepted entries into an Org logbook.
